## Contenido

`Red_Neuronal_Profunda_CNN.ipynb` incluye:

1. **Figura 1** – Red neuronal profunda de 5 capas (4-6-5-6-3) con pesos *w*, sesgos *b*, ReLU y Softmax.
2. **Figura 2** – Etapa convolucional paso a paso con NumPy (imagen 6×6 de una X, filtros diagonales, ReLU y max pooling).
3. **Modelo en Keras** – CNN con 3 capas ocultas (Conv2D → MaxPooling2D → Dense) entrenada con aprendizaje supervisado para clasificar X, O y +.
4. **Figura 3** – La red con las probabilidades predichas por el modelo entrenado.
